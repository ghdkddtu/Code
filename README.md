# Генератор паролей с авторизацией

Простой веб-сайт для генерации случайных паролей с системой входа.

## Описание

Сайт позволяет генерировать пароли после авторизации в системе.

## Вход в систему

**Доступные аккаунты:**

- Логин: `admin` / Пароль: `admin123`
- Логин: `user1` / Пароль: `user123` 
- Логин: `user2` / Пароль: `user123`

## Как использовать

1. **Войдите в систему** - введите логин и пароль
2. **Сгенерируйте пароль** - укажите длину и нажмите "Сгенерировать"
3. **Скопируйте результат** - используйте сгенерированный пароль

## Что используется

- **Flask** - для backend
- **SQLite** - для хранения данных  
- **HTML** - для интерфейса
